SAM ETHNAN AIR FORCE BASE COMMUNITY GUIDE
============================================

Open index.html in a browser. Keep index.html, style.css and script.js together.

This version includes:
- Responsive community-guide design
- New Resident & Visitor Guide
- Schools section
- UBA / Financial Services section
- Recreation and worship cards
- Search and category filters
- Google Maps search links where public locations are available
- Map placeholders where exact locations should be verified
- New Resident checklist
- Visitor guidance
- Back-to-Top button
- Mobile navigation
- Accessibility-friendly semantic structure

DATA SAFETY
-----------
Do not replace "Information to be verified" with guessed information.
Before publishing, independently verify school details, UBA service-point details,
images and exact Google Maps locations. The site intentionally avoids invented
phone numbers, addresses, opening hours and emergency contacts.

IMAGES
------
The cards currently use clearly labelled visual placeholders. Add verified/public
photographs only when you have permission or a suitable public source. Do not make
a generic image look like a photograph of the actual location.
